# Fuentes Java 2D

Proyecto desarrollado en **Java** utilizando **Apache NetBeans** y **Java 2D**.

## Descripción

Este programa permite crear y editar texto con diferentes efectos visuales similares a **WordArt de Microsoft Word**.

El usuario puede escribir un texto y modificar su apariencia mediante diferentes opciones de formato.

## Funciones principales

- Cambiar el texto mostrado.
- Seleccionar diferentes tipos de fuente.
- Modificar el tamaño del texto.
- Aplicar negrita y cursiva.
- Cambiar el color de relleno.
- Cambiar el color del contorno.
- Modificar el grosor del contorno.
- Aplicar relleno sólido o degradado.
- Mostrar únicamente el contorno del texto.
- Aplicar sombra al texto.
- Cambiar la posición horizontal y vertical de la sombra.
- Aplicar perspectiva.
- Rotar el texto.
- Restablecer la configuración.
- Visualizar los cambios en tiempo real.

## Tecnologías utilizadas

- Java
- Java Swing
- Java 2D
- Graphics2D
- Apache NetBeans

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir **Apache NetBeans**.
3. Seleccionar **File > Open Project**.
4. Abrir la carpeta del proyecto.
5. Ejecutar el proyecto presionando **F6**.

## Objetivo

Desarrollar una interfaz gráfica que permita editar fuentes en 2D y aplicar diferentes estilos visuales, incluyendo efectos tipo WordArt, perspectiva y sombras.
